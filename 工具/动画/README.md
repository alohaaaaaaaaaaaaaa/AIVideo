# 独立动画工具

在新工作室根目录使用本项目 `.venv`。不用旧工程，不需要剪辑软件，无生成式 API 调用。

```bash
.venv/bin/python -m pip install -r 工具/动画/requirements.txt
.venv/bin/python 工具/动画/核验动画数据.py
.venv/bin/python 工具/动画/渲染范例.py --config 工具/动画/配置/星月_转身找金星_8秒.json
```

其他离线配置：`星月_完整46秒.json`、`日历_翻页8秒.json`、`曝光_10秒.json`、`雷达_完整问答6.8秒.json`、`汇聚_空间汇合8秒.json`。统一入口均输出 H.264/yuv420p/25fps、无声音 MP4、完整解码记录及六帧联系表。声音交给工作室的默认声音流程。

`渲染范例.py` 的配置路径、输入路径、输出路径都相对新工作室根目录，不能越界；工作目录可以任意。`--config` 不接受外部绝对路径。核心引擎仍带原案例文案，只供复现。新题从 `配置/新题动画设计单.json` 建立设计，不要改历史复现配置里的日期然后直接渲染。

新天文选题：填写 `配置/新题星历查询模板.json` 的全部未知值，运行：

```bash
.venv/bin/python 工具/动画/取回新题星历.py --config 作品/本期/资料/星历查询.json --output 作品/本期/资料/JPL_本次查询
```

该工具查询免费官方接口，不使用 API key。已有输出目录拒绝覆盖；不完整结果标为 `incomplete_do_not_render`。保存的数据供新题渲染器使用，不会自动替换历史星月范例。成功取回后仍需核验日期、站位、时区、模型范围，才能将结果用作画面。

正式制作规则详见 [科学动画与星月范例](../../文档/04_科学动画与星月范例.md)。统一入口不要求 PyAV；汇聚历史引擎直接 `--preview` 的专用命令使用 PyAV，可优先用统一入口。
