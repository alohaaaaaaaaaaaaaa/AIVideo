# MiniMax 开放平台文档中心

- [概览](https://platform.minimaxi.com/docs/guides/models-intro.md): MiniMax 模型体系涵盖语言、视频、语音、图像与音乐五大方向，助力开发者高效构建智能应用。
- [前置准备](https://platform.minimaxi.com/docs/guides/quickstart-preparation.md): 在开始使用 MiniMax API 之前，需要完成账户注册和 API Key 获取。
- [通过 SDK 接入](https://platform.minimaxi.com/docs/guides/quickstart-sdk.md): 使用 Anthropic SDK 快速接入 MiniMax API，开始调用 MiniMax-M3 模型。
- [模型调用](https://platform.minimaxi.com/docs/guides/text-generation.md): MiniMax 语言模型，支持多语言编程、Agent 工作流等复杂任务场景。
- [Prompt 缓存](https://platform.minimaxi.com/docs/api-reference/text-prompt-caching.md): 通过 Prompt 缓存，可以有效降低延迟和成本。
- [工具使用 & 交错思维链](https://platform.minimaxi.com/docs/guides/text-m3-function-call.md): MiniMax-M3.1-Flash 是一款 Agentic Model，具备优秀的工具使用 (Tool Use) 能力。
- [服务端工具（Server Tools）](https://platform.minimaxi.com/docs/guides/server-tools.md)
- [视频生成](https://platform.minimaxi.com/docs/guides/video-generation.md): 本文档介绍 MiniMax 视频生成服务（MiniMax H3、MiniMax H3 Max）的使用方法，助力高效创作视频内容。
- [H3亮点功能示例](https://platform.minimaxi.com/docs/guides/video-prompt.md): 通过一组典型示例，展示 MiniMax H3 在原生多模态理解与生成、多模态精准编辑与控制、商用级多场景内容生成三大能力下的实际输出效果。
- [语音识别](https://platform.minimaxi.com/docs/guides/speech-to-text.md): MiniMax ASR 将音频转写为文本，支持流式返回、说话人分离与字幕导出，可直接用于会议纪要、播客/视频转写、内容审核、通话质检等场景。
- [音色快速复刻](https://platform.minimaxi.com/docs/guides/speech-voice-clone.md): MiniMax 语音模型提供良好的音色复刻能力，使用您的语料进行音色复刻，得到试听音频与 Voice ID（供后续正式语音合成使用）。
- [同步语音合成](https://platform.minimaxi.com/docs/guides/speech-t2a-websocket.md): 同步语音合成支持基于文本到语音的同步生成，单次可处理最长 10,000 字符的文本。
- [异步语音合成](https://platform.minimaxi.com/docs/guides/speech-t2a-async.md): MiniMax 提供异步语音合成 API，适用于长文本的音频合成任务，单个文件长度限制小于 10 万字符。
- [系统音色列表](https://platform.minimaxi.com/docs/faq/system-voice-id.md): 本文档列举了MiniMax开放平台全部的系统音色，为您提供语音合成选择。参考以下表格的内容，可查阅目前全部的系统音色的ID(Voice ID)、名称及支持语言，方便开发者快速查询与调用。
- [图片生成](https://platform.minimaxi.com/docs/guides/image-generation.md): 图片生成服务提供文生图（text-to-image）与图生图（image-to-image）两种核心功能。
- [音乐生成](https://platform.minimaxi.com/docs/guides/music-generation.md): 通过 prompt 参数定义音乐的风格、情绪和场景，通过 lyrics 参数提供演唱的歌词内容。该功能可用于为视频、游戏或应用快速生成独特的背景音乐和主题曲。
- [MiniMax MCP](https://platform.minimaxi.com/docs/guides/mcp-guide.md): 本文档介绍模型上下文协议（MCP）的原理与应用，提供 Python 与 JS 版本工具说明，支持语音合成、音色克隆、图像与视频生成等多模态能力，助力开发者高效集成 AI 功能。
- [M Plan MCP](https://platform.minimaxi.com/docs/guides/token-plan-mcp-guide.md): M Plan MCP 提供了两个专属工具：**网络搜索** 和  **图片理解**，帮助开发者在编码过程中快速获取信息和理解图片内容。
- [本地运行与自托管部署 MiniMax 开放模型](https://platform.minimaxi.com/docs/guides/local-deploy.md): 为 MiniMax-M3、MiniMax-M2.7、MiniMax Music 3 和 MiniMax H3 选择本地运行或自托管路径。
- [自托管部署 MiniMax-M3](https://platform.minimaxi.com/docs/guides/local-deploy-m3.md): 运行 MiniMax-M3 的 SGLang 实验性基线，验证服务，并规划安全的自托管部署。
- [部署 MiniMax-M2.7](https://platform.minimaxi.com/docs/guides/local-deploy-m2-7.md): 参考 SGLang Cookbook 部署 MiniMax-M2.7，并通过 OpenAI 兼容接口验证推理、思考内容和工具调用。
- [自托管部署 MiniMax Music 3](https://platform.minimaxi.com/docs/guides/local-deploy-music-3.md): 使用固定版本的 SGLang-Omni 部署 MiniMax Music 3，并通过 Speech API 生成歌曲。
- [本地运行与自托管部署 MiniMax H3](https://platform.minimaxi.com/docs/guides/local-deploy-h3.md): 使用 ComfyUI 本地运行 MiniMax H3，或通过 SGLang 部署可复现的 H3-Base 服务。

- [创建视频生成任务](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-create.md): 视频生成 V2 接口，通过多模态 content 数组输入（文本 / 图片 / 视频 / 音频），可通过 `model` 字段切换 MiniMax H3、MiniMax H3 Highspeed、MiniMax H3 Lite 与 MiniMax H3 Max，覆盖文生视频、图生视频（首尾帧）、多模态参考生视频，最高 2K 输出。<br /><br />提示：若需要使用 MiniMax H3、MiniMax H3 Highspeed、MiniMax H3 Lite 或 MiniMax H3 Max，请点击 [按量购买 API](https://platform.minimax.cn/docs/…
- [查询任务](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-query.md): 按 task_id 查询最近 7 天内单个视频生成、H3-Context-IR 或视频再生成任务的状态与结果。
- [查询任务列表](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-list.md): 分页查询最近 7 天内的任务列表，支持按状态、任务 ID、模型和任务类型过滤。
- [取消或删除任务](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-delete.md): 按任务当前状态取消排队中的任务，或删除成功和失败的视频生成、H3-Context-IR 及视频再生成任务记录。
- [创建 H3-Context-IR 任务](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-h3-context-ir.md): 深度理解多模态上下文，并生成结构化、语义更丰富的视频提示词。
- [创建视频再生成任务](https://platform.minimaxi.com/docs/api-reference/video-generation-v2-regeneration.md): 对符合 MiniMax-H3 768P 输出规格的源视频再生成为 2K 视频。
- [文生视频生成任务](https://platform.minimaxi.com/docs/api-reference/video-generation-t2v.md): 使用本接口输入文本内容，创建视频生成任务。
- [图生视频任务](https://platform.minimaxi.com/docs/api-reference/video-generation-i2v.md): 使用本接口输入图片及文本内容，创建视频生成任务。
- [首尾帧生成视频](https://platform.minimaxi.com/docs/api-reference/video-generation-fl2v.md): 使用本接口上传首尾帧图片及文本内容，创建视频生成任务。
- [主体参考视频生成任务](https://platform.minimaxi.com/docs/api-reference/video-generation-s2v.md): 使用本接口上传人物主体图片及文本内容，创建视频生成任务。

- [同步语音合成](https://platform.minimaxi.com/docs/api-reference/speech-t2a-http.md): 通过 HTTP 请求一次提交完整文本并返回合成音频，支持流式输出。
- [同步语音合成](https://platform.minimaxi.com/docs/api-reference/speech-t2a-websocket.md): 通过 WebSocket 连接由客户端按句发送文本，流式返回合成音频，适合低延迟的实时播报。
- [双向流式语音合成](https://platform.minimaxi.com/docs/api-reference/speech-t2a-websocket-bidi.md): 通过 WebSocket 连接按任意粒度（含逐字）流式发送文本，由服务端自动攒句合成，适合对接大模型流式输出。
- [创建异步语音合成任务](https://platform.minimaxi.com/docs/api-reference/speech-t2a-async-create.md): 使用本接口，创建异步语音合成任务。
