# 证据画面：原文值得被看见

这里保存的参考不是“好看的新闻卡片模板”，而是上一部成片中已经建立的工作方法：真实页面、清楚上下文、随着旁白推进的少量高光、底部一处来源。

`平湖原文高光/`包含真实段落截图、原页环境、原项目已采用的画面、原项目带声音预览、央视节目实录的新浪转载文本，以及截图捕获记录和档案源码。`迁移来源清单.json`记录所有复制文件的旧项目相对路径和SHA256。旧项目没有被移动或改写。

`原项目声画预览_仅作参考.mp4`保留当时的表达、原文高光和声音关系，是学习参考，不应把它直接拼入所有选题。`原项目截图捕获源码_档案.py`保存历史实现，会提到旧项目路径；只用于追溯。新选题用可独立运行的`工具/媒体/evidence_highlight.py`。

新闻材料的原文明确说的是4月27日的平湖直升机案例。它是“小型航空器可以影响大型机场航班”的具体例子，不是萧山7月7日晚的独立身份识别证据。引用时保留这个适用范围，不能把两个事件剪成一件。

可直接播放`通用工具重制示例.mp4`查看新的独立工具效果；`高光示例配置.json`标注的是原始段落截图上的像素范围。工具只做缩放、遮罩/高光和一处底注，不重打新闻正文，不捏造网页栏目或媒体印章。原文来源：央视《经济半小时》节目实录，新浪2010-11-19转载，http://news.sina.com.cn/c/sd/2010-11-19/065721497404.shtml 。

新题材照搬的是方法：先查证原文、保存上下文，再安排视觉。财经需要保留数据口径、币种、统计期间；黑客事件需要保留公告版本、披露日期、事件与漏洞编号的对应。社交媒体留言保留用户、时间和原文；个人转述不能做成“同期官方通报”的外观。原有截图带完整底注时不再叠左上角解释；动态素材已有说明时不再叠底注。
