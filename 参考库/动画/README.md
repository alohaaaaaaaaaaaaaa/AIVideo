# 啊子牙 · 动画参考库

[打开看片入口](看动画参考.html) · [完整制作方法](../../文档/04_科学动画与星月范例.md)

这是从已完成的萧山视频中独立保留下来的制作参考。保留了实际成片、真实数据、原源码与迁移后的可运行引擎。它教新项目怎样做调查动画，不把萧山的坐标、日期或结论当成新题事实。

| 目录 | 已保留内容 | 新题使用方式 |
|---|---|---|
| `01_星月与日期` | JPL 原始响应/参数、七节点数据、坐标复算、原天空和日期源码、代表镜头 | 空间/方向问题参考 ENU 天穹；日期问题参考翻页和时区拨针；事实全部重查 |
| `02_曝光与雷达` | 积分曝光代码、雷达机制代码、正式曝光镜头、已去空等问答镜头 | 用可复算的过程解释机制，播放一遍完整动作 |
| `03_六路汇聚` | 当前三维版源码、真实来源截图、空间样品 | 先分清证据类别，再汇合解释；不用平面卡片墙 |
| `字体` | Noto Sans CJK SC Regular/Bold、SIL OFL 1.1 | 独立源码的通用中文正文 sans；不是水印字体 |
| `检查` | 五引擎实际输出帧、迁移检查记录 | 检查代码在新环境可运行、布局是否仍然清楚 |

原文件副本与哈希见 `原文件复制清单.json`。历史源码保留原状；运行新项目请使用 `工具/动画/渲染范例.py`，不执行历史源码中的旧路径入口。

两类文件不能混淆：`成片参考` 是旧项目已产生的画面；`独立重渲染` 是本新项目本地渲染的结果。重渲染字体使用可分发的 Noto；原片保持原字型。源数据的旧项目路径是历史记录字段，不是新入口的运行依赖。

一分钟星历的历史请求全部失败，已放入 `01_星月与日期/数据/历史失败请求`，不参与渲染。实际采用的时间变化为每 20 分钟七个保存节点及明确的动画插值。
