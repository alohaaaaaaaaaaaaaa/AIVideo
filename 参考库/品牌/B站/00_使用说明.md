# 啊子牙常用水印 · B站无账号版

本版仅保留“啊子牙”，没有第二行账号文字。适用于 B站及其他需要纯署名的发布场景。沿用确认过的悠哉手写字和透明镂空浮雕轮廓。

## 怎么用

1. 在剪映、Premiere、DaVinci Resolve 等剪辑软件中导入“透明PNG”里的文件，放在视频上方独立图层。
2. 1080p 视频使用 224 × 70 的 1080p PNG，4K 视频使用 448 × 140 的 4K PNG。高清母版为 896 × 280，可按需要缩放；缩放时锁定宽高比。
3. **图层不透明度设为 100%。** PNG 内已经保存最终轮廓透明度，无需再次降低图层透明度。
4. 水印保持镜头内静止。避开字幕、人脸、资料原文和重点标注；必要时只在少量切镜处换位，不做持续移动或弹跳。
5. 导出后检查亮、暗画面及换位边界，确认水印清晰且不遮挡内容。

## 文件内容

- `透明PNG/`：1080p、4K、高清母版三份透明素材。
- `预览/水印样式.jpg`：深浅背景上的效果示意，不能代替透明 PNG 使用。
- `字体/`：Yozai Medium 字体及 OFL 许可文本。
- `源文件/`：裁切后的原始字形蒙版和可重建水印的 Python 脚本。
- `检查/重建核验.json`：三份 PNG 与本次制作素材逐像素一致的核验结果。
- `校验清单.json`：包内文件的 SHA-256，供备份、迁移后核对完整性。

如需重建，在安装 Pillow 的 Python 环境执行 `python 源文件/重建水印.py`；会重新生成本包的三份透明 PNG。不要用不明字体替换字体文件，以免字形变化。
